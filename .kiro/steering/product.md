# Product: Field-to-Fix

Agentic V-cycle for automotive OEMs that starts at the **field** (top-right of the V): public complaints and
in-vehicle bug reports become a verified, signed, targeted OTA, with a human approving the release.

- Users: head-unit / infotainment engineering, release owners, quality (field) teams at an OEM.
- Hero flow (MVP): Bluetooth audio stutter + Android Auto drop after cold start on HU-2.3.1, fixed in HU-2.3.2.
- Every stage must leave evidence (StageRun: summary, reasoning, artifacts, links) suitable for ASPICE / UNECE R156 audits.
- Never fake: if a connector is not configured it runs in *simulated* mode and the UI says so.
